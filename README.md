# motor-de-aula

Motor de apresentação de aula. Mostra no navegador um deck em PDF, página a página, troca as páginas marcadas por animações HTML que o passador de slides controla, e abre votações em que a turma responde pelo celular ou pelo computador a partir de um QR code.

O motor aceita o PDF de qualquer template. Ele é opinativo: as animações, as regras de tela e as verificações de acessibilidade (tamanho de letra e contraste) seguem um jeito específico de dar aula.

O código ainda está sendo migrado para cá; o plano está nas issues.
